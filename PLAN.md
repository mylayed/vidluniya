# 🎧 Відлуння — план розробки

> Голосові капсули на карті: користувач записує голосове й «закопує» його в точці на карті. Прослухати можна лише фізично прийшовши туди (і, за бажанням, після певної дати). **Місце — це ключ доступу.**

## 1. Стек і ключові рішення

| Шар | Рішення |
| --- | --- |
| Клієнт | React Native (Expo), TypeScript, expo-router |
| Карта | react-native-maps (Google/Apple Maps) з кастомним темним/світлим стилем; Mapbox — опція пізніше |
| Геолокація | expo-location + геофенсинг для фонових сповіщень «поряд капсула» |
| Аудіо | expo-audio (запис AAC), нормалізація гучності на сервері |
| Бекенд | Supabase: Postgres + **PostGIS**, Auth (Google/Apple), Storage (приватний бакет для аудіо), Edge Functions |
| Захист доступу | Аудіо віддається лише через Edge Function після серверної перевірки координат; підписані тимчасові URL |
| AI | Транскрипція (Whisper) → модерація тексту + субтитри й теги |
| Пуші | Expo Notifications |
| Аналітика | PostHog |
| Платежі | App Store / Google Play IAP (через RevenueCat); бізнес-пакети — за рахунком поза сторами |
| Мови | українська та англійська (i18n з першого дня) |
| Теми | темна (основна) і світла |

### Дизайн-токени
- **Шрифти:** Unbounded — заголовки й назви; Manrope — увесь інтерфейс (Google Fonts через expo-font)
- **Темна тема:** ніч `#0E1013`, поверхня `#181B20`, текст `#F2F3F5`, другорядний `#9AA0AA`, акцент капсул `#8B7CFF`, капсули часу `#F5B544`
- **Світла тема:** фон `#F5F6F8`, акцент `#5A47F0`

## 2. Структура репозиторію

```
app/                      # екрани (expo-router)
  (onboarding)/  (auth)/  (tabs)/map  (tabs)/profile  capsule/[id]  record/  quest/
src/
  components/             # спільні UI-компоненти (хвиля, плеєр, кнопки)
  theme/                  # токени, світла/темна тема
  i18n/                   # uk.json, en.json
  lib/supabase/           # клієнт, типи БД
  features/
    map/  capsule/  record/  quest/  profile/  notifications/
supabase/
  migrations/             # схема, PostGIS, RLS
  functions/
    open-capsule/         # перевірка позиції → підписаний URL
    create-capsule/       # валідація точки, лімітів, геозон
    moderate/             # транскрипція + AI-модерація
    notify/               # пуші
    lifecycle-cron/       # строки життя капсул
```

## 3. Модель даних

| Таблиця | Поля (основне) |
| --- | --- |
| `users` | id, nickname, avatar, language, phone_verified, created_at, plan |
| `capsules` | id, author_id, location (geography), radius, audio_path, duration, transcript, title, hint, visibility (public / private / quest), recipient_id, unlock_at, password_hash, is_anonymous, is_remote, moderation_status, status (active / sleeping / deleted), expires_at, created_at |
| `discoveries` | user_id, capsule_id, found_at |
| `echoes` | id, capsule_id, author_id, audio_path, moderation_status, created_at |
| `quests` / `quest_steps` | маршрут, порядок точок, підказки між ними |
| `reports` | id, capsule_id, reporter_id, category, status, created_at |
| `devices` | device_id, user_id — для банів за пристроєм |
| `blocked_zones` | geography полігонів, де заборонено ставити капсули (школи, військові об'єкти, приватні будинки) |

Принципи:
- RLS на всіх таблицях; точні координати й `audio_path` клієнту напряму не віддаються.
- RPC `capsules_nearby(lat, lng, radius)` повертає розмиті точки; точна — лише в радіусі ~300 м.
- Історія переміщень користувача **не зберігається** — лише факт знахідки.

## 4. Етапи розробки

### Етап 0 — Підготовка (2–3 дні)
- [ ] Акаунти: Apple Developer, Google Play Console, Supabase, PostHog
- [ ] Заявка в Apple Small Business Program (комісія 15%)
- [ ] Git-репозиторій, EAS Build, ESLint + Prettier, базовий CI

### Етап 1 — Прототип (2–3 тижні)
- [ ] Expo-проєкт, навігація, теми, шрифти, i18n
- [ ] Supabase: таблиці, PostGIS, RLS, Auth (Google/Apple)
- [ ] Онбординг — 3 слайди + дозволи на геолокацію й мікрофон; екран входу
- [ ] Карта з капсулами в радіусі: розмиті «хвилі», фільтри (публічні / мої / для мене / квести)
- [ ] Запис аудіо до 60 с, назва, підказка, вибір точки (поточна або в межах ~100 м), завантаження у Storage
- [ ] Відкриття капсули лише в зоні 50 м — перевірка на сервері (`open-capsule`): відстань, точність сигналу, неможливі «стрибки»
- [ ] Екран наближення: індикатор «тепло-холодно», вібрація при вході в зону 50 м
- [ ] Плеєр з анімацією хвилі, автор (або анонімно), дата запису

**Готово, коли:** на двох телефонах один записує капсулу, інший відкриває її лише фізично на місці.

### Етап 2 — MVP (3–4 тижні)
- [ ] Капсули часу (`unlock_at`)
- [ ] Особисті капсули для конкретної людини + посилання-запрошення; пароль як додатковий замок
- [ ] Транскрипція + AI-модерація до публікації (образи, телефони, адреси, прізвища, спам, ознаки закладок) + субтитри
- [ ] Пуш-сповіщення та геофенсинг: «поряд є капсула», «для тебе залишили капсулу», «твою капсулу знайшли»
- [ ] Профіль: мої капсули, знайдені, статистика, налаштування, завантаження / видалення своїх записів
- [ ] Скарги; категорія «Наркотики / незаконне» — миттєве приховування до розгляду
- [ ] Антизловживання: верифікація номера телефону, обмеження нових акаунтів на 7–14 днів, поведінкові прапорці, бан за пристроєм, геозони-винятки
- [ ] Запобіжники публічних капсул: «Публічна» не типовий вибір, попередження перед публікацією, фільтр голосу для анонімів
- [ ] «Дай — отримай» для першої капсули в місті
- [ ] Режим прогулянки (автовідтворення в навушниках)
- [ ] Життєвий цикл капсул (cron): строки зберігання, нагадування за 30 днів, «сплячий» стан на 90 днів
- [ ] Нестабільний GPS: запасна геолокація з Wi-Fi / мереж, повідомлення «GPS зараз нестабільний»
- [ ] Правила користування, політика приватності, консультація юриста, процедура відповіді на запити Кіберполіції

**Готово, коли:** усі 9 екранів MVP працюють на iOS та Android, модерація блокує тестові порушення.

### Етап 3 — Запуск по Україні (3–4 тижні)
- [ ] Знайти амбасадорів в обласних центрах (краєзнавці, гіди, музеї, студентські спільноти)
- [ ] Засіяти 20–30 капсул у кожному обласному центрі
- [ ] Всеукраїнський стартовий квест (по капсулі в кожному обласному центрі, карта прогресу, призи)
- [ ] Теплова карта України на екрані карти
- [ ] TestFlight / закрите тестування Android
- [ ] Тест відкриття капсул у реальних умовах під час тривог
- [ ] Промо-відео в TikTok / Reels / Shorts, співпраця з міськими блогерами
- [ ] Збір фідбеку, публікація в App Store та Google Play

### Етап 4 — Ріст
- [ ] Конструктор квестів
- [ ] Відлуння — голосові відповіді на капсулу
- [ ] Plus-підписка та капсула-подарунок
- [ ] Тариф «Автор» і платні маршрути (70% автору / 30% платформі від чистої суми)
- [ ] Бізнес-квести з QR/NFC-мітками (оплата за рахунком поза App Store)
- [ ] Бізнес-профілі закладів: верифікація, ролі (власник / персонал), мережі
- [ ] Менші міста й туристичні локації (Карпати, замки, нацпарки)

| Активні капсули | 10 | без обмежень | без обмежень |
| Капсули часу | до 1 року | 5–10 років | 5–10 років |
| Приватні квести | 1, до 3 точок | без обмежень | без обмежень |

| Платні маршрути, статистика, верифікація | — | — | ✓ |

- Беззбитковість ≈ 25–30 підписників Plus (фіксовані витрати ≈ $43/міс).

## 6. Ризики та запобіжники

| Ризик | Що робимо |
| --- | --- |
| Порожня карта (холодний старт) | Засів контенту, амбасадори, стартовий квест, «Дай — отримай», теплова карта |
| РЕБ / спуфінг GPS | Fallback Wi-Fi/мережі, серверна перевірка стрибків і точності, зрозуміле повідомлення, тести під час тривог |
| Зловживання (закладки, сталкінг, доксинг) | Радіус 50 м без точної точки, заборона контактів у підказках, модерація всіх капсул, поведінкові прапорці, бан за пристроєм |
| Приватність | Анонімність на вибір, геозони-винятки, без історії переміщень |
| Невиконана обіцянка зберігання | Гарантоване зберігання капсул часу, нагадування й «сплячий» стан перед видаленням |
| Юридичні | Правила користування, юрист до запуску, процедура запитів Кіберполіції |

## 7. Ідеї на потім
- **Капсули для дому, куди поки не можна повернутися** ⭐ — головна історія для запуску
- Нічні та погодні капсули, подієві капсули на фестивалях
- «Голос міста» — щотижнева добірка в подкаст
- AR-режим, колективні капсули, сімейний архів, самознищення
- Мандрівна капсула, паспорт міст з бейджами
- AI-переклад для туристів, віджет і Live Activity «Поряд 2 капсули»
